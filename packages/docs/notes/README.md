# 前端知识点

前端开发常见知识点的系统整理，按主题划分为五个部分，可作为快速查阅手册，也适合按顺序通读复习。

| 专题 | 内容 |
| --- | --- |
| [HTML](./html.md) | 语义化标签、表单验证、音视频、Canvas 与 SVG、script 加载、可访问性 |
| [CSS](./css.md) | 盒模型与 BFC、层叠上下文、Flex/Grid 布局、响应式与 1px/Retina 适配、变量与预处理器、动画 |
| [JavaScript](./javascript.md) | 类型与转换、作用域与闭包、原型与继承、this、异步编程（Event Loop/Promise/Generator）、DOM 与事件、BOM 与本地存储 |
| [TypeScript](./typescript.md) | 类型标注、interface 与 type、泛型、工具类型、类型守卫 |
| [Vue](./vue.md) | Vue 2/3 响应式原理与对比、生命周期、组件通信、组合式 API、常见易错点 |
| [浏览器与网络](./browser-network.md) | 从输入 URL 到渲染、重绘与回流、HTTP 缓存、跨域、Web 存储 |
| [工程化](./engineering.md) | 模块化、构建工具、代码质量、Git 流程、性能优化与发布 |

## 如何使用本手册

- 每个专题以「结论先行」的方式给出要点，再展开细节与代码示例；
- 示例代码均可直接在浏览器控制台或项目中验证；
- 遇到不熟悉的条目，建议先看结论，再动手跑一遍示例加深记忆。
